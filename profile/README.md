# QuantCoda

面向开发者和 AI Agent 的 A 股数据 API，覆盖行情、财务、资金流，以及 ETF 和指数数据。

*China market data for Python, REST, and AI agents.*

- **REST API** · [接口文档](https://quantcoda.com/docs)
- **Python SDK** · [快速开始](https://quantcoda.com/python-sdk) · [PyPI](https://pypi.org/project/quantcoda/)
- **MCP Server** · [AI Agent 接入指南](https://quantcoda.com/mcp-server)

```bash
pip install quantcoda
```
